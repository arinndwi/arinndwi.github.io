Tentang Saya

Hallo Nama saya Arin Dwi Utama

Saya adalah murid SMKN 1 Tangerang yang sedang duduk di bangku kelas XII DKV 1. Website ini dibuat untuk memenuhi tugas yang diberikan oleh guru saya, yaitu Pak Mawan.

Melalui jurusan Desain Komunikasi Visual (DKV) yang saya tekuni, saya belajar banyak hal seputar dunia desain, media digital, dan kreativitas visual. Pengalaman ini memotivasi saya untuk terus mengasah keterampilan agar nantinya dapat berkarya secara profesional di bidang industri kreatif.

Besar harapan saya agar website ini dapat bermanfaat, tidak hanya untuk menyelesaikan tugas sekolah, tetapi juga sebagai wadah untuk membagikan informasi serta portofolio karya saya selama belajar di sekolah.
